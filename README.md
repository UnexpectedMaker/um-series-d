# Contents
In this repo you'll find the following items:

## 3D Models
3D STEP files for each of the TinyS3[D], ProS3[D], FeatherS3[D], EdgeS3[D], TinyPICO[D] and TinyC6[D] boards

You'll also find a STEP file for the EdgeS3[D] Reference Carrier board and a STEP for the M.2 connector footprint with the EdgeS3[D] inserted to help line things up.

## Schematics
PDF Schematics for each of the TinyS3[D], ProS3[D], FeatherS3[D], EdgeS3[D], TinyPICO[D] and TinyC6[D] boards.

## Code
Helper libraries, examples and shipping files for Arduino, ESP-IDF, MicroPython and CircuitPython - see the [code folder](code/) for details.

## KiCAD (v9)
Symbol and Footprint for EdgeS3[D] and a project folder for the EdgeS3[D] Reference Carrier PCB.

## Pin Reference Cards
Hi-res pinout reference cards for each of the TinyS3[D], ProS3[D], FeatherS3[D], EdgeS3[D], TinyPICO[D] and TinyC6[D] boards
